# Standalone Solidity compiler: licence and corresponding source

`minutus-solidity-compiler` is a separate GPL-3.0-only Swift/JavaScriptCore
program. Its complete source is `compiler.swift`, with its actual build script
`build.py` and hardened-runtime entitlements alongside it in this directory.
The enclosing Minutus application communicates with it through a bounded
standard-JSON pipe; this resource does not change the application's licence.

To rebuild on Apple Silicon macOS with the Xcode command-line tools and Python 3:

```sh
python3 build.py ./minutus-solidity-compiler
```

This compiles with `swiftc -O` and applies a local ad-hoc code signature. The
helper uses only the macOS Foundation, JavaScriptCore and Darwin system
frameworks; no downloaded package or build-time generated source is required.
`--identity` selects an optional exact signing certificate hash. Rebuilding does
not replace the loaded application's pinned helper identity or grant execution
authority. The host must be rebuilt to adopt an independently reviewed helper.

The separately downloaded official Solidity compiler is GPL-3.0. Its complete
licence is `Solidity-GPL-3.0.txt`. `compiler-catalogue.json` lists the exact stable
official emscripten-wasm32 builds, SHA256 checksums and inventory provenance used
by this version. The compiler binary origin is
<https://binaries.soliditylang.org/emscripten-wasm32/>; corresponding upstream
source for each exact version is
`https://github.com/ethereum/solidity/tree/vVERSION` (substitute the release
version), with build instructions in that source tree. The public compiler cache
retains the licence and exact build/source provenance with each downloaded build.
Compiler binaries are not bundled in this application resource.

Independent Solidity input and generated bytecode retain their own applicable
licences. Compilation does not establish economic semantics or onchain source
correspondence. JavaScriptCore is supplied by macOS. The Rust supervisor is a
separate Apache-2.0 application component, not linked into the GPL helper.

The package's closed notice manifest verifies this full source, build script,
entitlements, catalogue and licence, as well as their canonical source copies.
