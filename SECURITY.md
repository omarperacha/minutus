# Reporting security vulnerabilities

Email private vulnerability reports to [hello@minutus.ai](mailto:hello@minutus.ai).
You may also use GitHub private vulnerability reporting.
Do not put exploit details or secrets in a public issue.

A useful private report identifies the affected commit or version, the relevant
trust boundary, reproducible steps using synthetic data, and the observed impact.
Never send wallet recovery phrases, private keys, passwords or real user data.

Minutus currently has no published support-window or security-response SLA.
For implemented boundaries and known release limitations, see
[security](docs/security.md) and [release process](docs/releases.md).
