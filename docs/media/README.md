# README media

- `minutus-banner.png`: 1280 × 640, opaque PNG using the Minutus mark,
  Cormorant Garamond wordmark, Inter and Minutus palette. Suitable for the README
  and GitHub social preview; below GitHub's 1 MB limit.
- `minutus-chat.gif`: 1100 × 720, 10.6 seconds, 106 frames at 10 fps, looping.
- `minutus-chat.png`: still alternative for readers who prefer no animation.

The walkthrough captures the actual React frontend with Tauri's IPC mock and
synthetic messages. The prompt, streamed response and project are scripted.
No model inference, private conversation, wallet, credentials or user files were
used. It demonstrates the interface, not model quality or response speed.

The logo and fonts come from the existing application assets. Font licences are
retained in `public/fonts/`; original assets follow the repository licence.

To set the repository social preview, upload `minutus-banner.png` under the
GitHub repository's **Settings → Social preview → Edit**. Embedding it in the
README does not set that repository setting automatically. See
[GitHub's instructions](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).
